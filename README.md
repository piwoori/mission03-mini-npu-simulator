# Mission 03 - Mini NPU Simulator

## 1. 프로젝트 소개

Mini NPU Simulator는 입력 패턴과 필터 간의 **MAC(Multiply-Accumulate)** 연산을 수행하여
입력 패턴이 Cross(+)와 X 중 어느 형태에 가까운지 판정하는 Python 콘솔 프로그램입니다.

본 프로젝트에서는 Python 기본 문법만 사용하여 MAC 연산을 직접 구현하였으며,
사용자 입력 모드와 `data.json` 자동 분석 모드를 제공합니다.

---

## 2. 실행 방법

프로젝트 디렉토리에서 아래 명령어를 실행합니다.

```bash
python3 main.py
```

프로그램 실행 후 원하는 모드를 선택합니다.

```
=== Mini NPU Simulator ===
[모드 선택]
1. 사용자 입력 (3x3)
2. data.json 분석
```

- **1번** : 3×3 필터와 패턴을 직접 입력
- **2번** : `data.json` 파일을 이용한 자동 분석

> `data.json`은 `main.py`와 같은 디렉토리에 위치해야 합니다.

---

## 3. 구현 내용

### 3.1 MAC(Multiply-Accumulate) 연산

동일한 위치의 패턴과 필터 값을 곱한 후,
모든 결과를 누적하여 하나의 점수를 계산합니다.

```python
score += pattern[row][column] * filter_data[row][column]
```

---

### 3.2 사용자 입력 모드

사용자는 다음 순서대로 입력합니다.

1. 필터 A 입력
2. 필터 B 입력
3. 패턴 입력

프로그램은 다음 정보를 출력합니다.

- A 점수
- B 점수
- 평균 연산 시간(10회)
- 최종 판정(A / B / 판정 불가)

---

### 3.3 data.json 분석 모드

프로그램은 다음 순서로 동작합니다.

1. 필터 로드
2. 패턴 분석
3. MAC 연산
4. PASS / FAIL 판정
5. 성능 분석
6. 결과 요약

패턴 이름(`size_5_1`)에서 크기 정보를 추출하여
해당 크기의 필터를 자동으로 선택합니다.

예시

```
size_13_2
      ↓
size = 13
      ↓
filters["size_13"]
```

---

### 3.4 동점 판정

부동소수점 오차를 고려하기 위해 다음 기준을 사용했습니다.

```python
epsilon = 1e-9

if abs(cross_score - x_score) < epsilon:
    return "UNDECIDED"
```

---

### 3.5 입력 검증

다음 사항을 검증합니다.

- 숫자가 아닌 입력
- 한 줄에 숫자가 3개가 아닌 경우
- JSON 데이터의 필터와 패턴 크기 불일치

크기가 일치하지 않을 경우 프로그램을 종료하지 않고
FAIL 처리 후 다음 테스트를 수행합니다.

## 6. 시간 복잡도 분석

MAC 연산은 모든 행과 열을 한 번씩 순회합니다.

```python
for row in range(len(pattern)):
    for column in range(len(pattern[row])):
```

행과 열을 각각 N번 반복하므로

- 바깥 반복문 : N
- 안쪽 반복문 : N

총 연산 횟수는

```
N × N = N²
```

따라서 MAC 연산의 시간 복잡도는

```
O(N²)
```

입니다.

실제 실행 결과에서도

|크기|연산 횟수|
|---|---:|
|3×3|9|
|5×5|25|
|13×13|169|
|25×25|625|

입력 크기가 증가할수록 연산 횟수(9 → 25 → 169 → 625)가 증가하였으며, 평균 실행 시간 또한 함께 증가하는 것을 확인할 수 있었습니다.

이를 통해 MAC 연산의 시간 복잡도가 O(N²)임을 확인할 수 있습니다.

## 7. 실패 원인 분석

현재 제공된 `data.json` 기준으로 총 6개의 테스트를 수행하였으며,
3개의 테스트는 FAIL로 판정되었습니다.

실패한 케이스들은 모두 Cross와 X의 MAC 점수가 매우 비슷하게 계산되었습니다.

프로그램은 부동소수점 오차를 고려하기 위해

```python
abs(cross_score - x_score) < 1e-9
```

조건을 만족하면 두 점수를 동일한 값으로 판단하고
`UNDECIDED`를 반환하도록 구현하였습니다.

따라서 실제로는 Cross 또는 X와 유사한 패턴이더라도
두 점수 차이가 매우 작으면 판정하지 않고 FAIL 처리됩니다.

이는 구현 오류가 아니라
동점 처리 규칙을 검증하기 위한 테스트 데이터로 판단됩니다.
